# Build, check and test

Run the full quality pipeline for the marmotte monorepo (from the repo root).

## Commands

```sh
vp run build   # vp run -r build: every package, in dependency order
vp run test    # vp run -r test: unit tests + CLI scaffold integration tests
vp run check   # vp check: format (oxfmt) + lint (oxlint)
vp check --fix
vp run build:docs   # VitePress site (the per-package API reference is generated by `build`)
```

Target one package with `vp run @mrmt/vite#build` or `vp run marmotte#test`.

## What each step does

- **build** — `vp pack` (tsdown) compiles each package's `src/` to `dist/` as ESM with `.d.ts` files and generates its TypeDoc API reference into `docs/api/`. Results are cached; unchanged packages replay instantly.
- **test** — `vp test run`. Each `test` task first builds the package and its `@mrmt/*` dependencies. The CLI tests pack every workspace package into tarballs and scaffold real projects from them (slow, needs network).
- **check** — formatting and lint. It does not type-check: run `vp exec tsc --noEmit -p packages/<name>/tsconfig.json`.

## Fix cycle

Use `withTmpDir()` from `@mrmt/vitest` for filesystem-heavy tests.
